# Consolidate Specs Command

## SDD Framework Detection

Before executing command, read `adapters/detect.md` determine the active SDD framework. load `adapters/{framework}.md` path maps, command maps, gap fills. All paths commands below use adapter-mapped names the loaded adapter.

## Ponytail Core Contract

Before continuing, you **MUST** read and apply `{adapter_path:ponytail-template}` as the authoritative shared contract. Phase instructions may narrow but not weaken its safety or verification floor.

## Purpose

Provide the adapter's compact offline fallback for Budgeted Architecture Context Retrieval. It supplements active artifacts and never replaces them.

## Procedure

1. Resolve `{adapter_command:consolidate-specs}` and `{adapter_path:fallback-spec-index}`.
2. If consolidation is unsupported, execute `{adapter_command:list-specs}`, return that adapter-native index, and do not write a fallback artifact. Otherwise execute `{adapter_command:consolidate-specs}` and enumerate `{adapter_path:spec}` in normalized path order, excluding the fallback, generated artifacts, and explicitly archived sources.
3. If no source specs exist, report that no fallback was generated and leave any existing fallback untouched unless the user explicitly authorizes replacing it.
4. Read each source only far enough to extract its title or one-line purpose, requirement and acceptance-criteria identifiers, shared invariants, cross-feature dependencies, and explicit conflicts. Acceptance-criteria bodies remain in the source spec.
5. Deduplicate only statements that are clearly identical. Keep similar statements separate. Never resolve conflicts or ambiguity silently.
6. Write the complete generated artifact in one operation with the structure below. Keep feature entries to one line plus identifiers and provenance so the fallback does not become another full specification.

## Required Output

```markdown
# Generated System Context

> Generated by Architecture Guard. This non-authoritative fallback supplements active feature artifacts and must not replace them.

## Generation Metadata
- Generated At: [ISO-8601 timestamp]
- Source Count: [count]

## Shared System Invariants
- [Concise invariant with source paths]

## Feature Index
- **[Feature]** — [One-line purpose]; IDs: [requirement/acceptance IDs]; Source: [adapter-resolved spec path]

## Cross-Feature Dependencies
- [Dependency with source paths]

## Unresolved Conflicts and Ambiguities
- [Distinct statements and their source paths; use `None identified` when empty]

## Source Manifest
- [adapter-resolved spec path]
```
