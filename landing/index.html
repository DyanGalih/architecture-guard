How Architecture Guard Orchestrates SDD

From idea to implementation, verified and aligned.

1. Explore

Understand the problem and shape the change with AI assistance.

2. Propose

Define the change requirements, design, and tasks that align with architecture.

3. Plan

Break down work, validate scope, and prepare for delivery.

4. Implement

Build with confidence. Guardrails and context guide every decision.

5. Verify

Run automated reviews, tests, and security checks. Continuously.

6. Deliver

Ship high-quality software that stays true to the architecture.

Documentation Overview

Specification-Driven Development (SDD) & Guardrails

SDD Orchestration Workflows

Guides AI agents from idea to implementation safely with workflows like `governed-discover`, `governed-delivery`, and `governed-implement`.

OpenSpec & Spec Kit Governance

Detects the active SDD tool and applies matching artifact paths and commands, ensuring the AI conforms to the current framework.

Repository Hygiene Guard

Automatically detects stray draft files, orphaned code, and debug artifacts generated by AI before they hit your main branch.
