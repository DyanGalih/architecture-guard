Architecture Guard v3.6.0 Documentation

Specification-Driven Development, Multi-Agent Teams & PR Operations

1. Governed SDD Orchestration

Orchestrates changes across OpenSpec (openspec/), SpecKit (.specify/), and custom adapters. Commands like /ag-governed-discover, /ag-governed-delivery, and /ag-governed-implement run specs, plans, and tasks through auto-repairing verification loops.

2. Multi-Agent Host Coordination

Architecture Guard coordinates across coding agents:
• Claude Code: Native Agent Teams (agteam-*) with peer messaging and quality gates.
• Antigravity (AGY): Native subagent execution via invoke_subagent and workflows (agx-*).
• OpenCode: Lead-coordinated native subagents (agoc-*) with strict permission envelopes ("*": deny) and sequential fallback.
• OpenAI Codex: Scoped child sessions via .codex/skills/.

3. Deep Verification, Premise Grounding & 37 SonarLint Rules

Unlike standard linting, Architecture Guard verifies that planning artifacts cite true base-branch code (Premise Grounding), detects unlisted file readers/writers (Consumer Inventory), verifies artifact self-consistency, and enforces 37 architecture-focused SonarLint rules across Java, JavaScript, TypeScript, Python, and PHP alongside repository hygiene rules before code is pushed.

4. Backlog Queues, Per-Story Decomposition & Multi-Forge PR Automation

• /ag-governed-delivery-team: Decomposes features into parent and per-item child User Stories (user-stories/<feature>/<story-id>.md) and syncs to Jira Epics/Stories or GitHub Issues.
• /ag-governed-backlog: Ingests Jira, Beads (bd), or YAML backlogs and executes queue items across Full, Fix, Light, and Research lanes.
• /ag-pr-queue: Manages pull request reviews and feedback triage across GitHub, GitLab, Bitbucket, and Azure DevOps in isolated worktrees with batched human gates.
